1. Call app_guide (with the area as topic if they named one).
2. Look at their profile, goals and what is already set up, and pick the three areas that fit them best.
3. Explain those three in plain words, each with one concrete thing they can say right now. Mention what is already set up and what isn't (from the status).
4. Name the other areas in one short line each, grouped, so they know what exists.
5. Ask which one they'd like to try or set up now, and wait.
6. When they pick one, walk them through it step by step, doing the setup with your tools where you can.

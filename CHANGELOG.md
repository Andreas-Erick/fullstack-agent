- Built for years of daily use. *(Opening the app and the conversation list no longer reads every conversation you ever had: a small index keeps the list. Long conversations stay fast and cheaper on the Claude API: older turns fold into a running summary, only the last few replies are sent with their full tool results, and the stable part of the prompt, the tools and the conversation so far are cached by the API between messages. Old replies no longer keep their full tool results on disk (their text and the list of tools stay), so conversation files stop growing by megabytes. Vault notes and memories are written safely: a crash mid-write leaves the old note or the new one, never half of one. With hundreds of memories the prompt lists the 60 most recent and brings the ones that matter for each message in full, instead of growing forever. The prompt's vault reads run side by side, the log writes in small batches, and the note cache stays under about 32 MB. The speech models' runtime now comes with the app instead of a download from a CDN, so offline voice and speech recognition work without that site and the window can't load scripts from the internet. Long chats open at their latest 40 messages and load older ones as you scroll up, and the conversation list shows 100 at a time (search still covers all). When the assistant updates a structured note (habits, the skill tree, a learning topic, a deck, the stream) while you edit the same note in Obsidian, your edit is kept and the change is applied on top of it instead of overwriting it. Vault search reads notes side by side, folder indexes (like the list of daily notes) are only rebuilt when a note is added or removed, and the vault's history is packed about once a week.)*

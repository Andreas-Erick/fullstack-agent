      Skill tree

      Architecture

      Habits

      Tick off what you did today, or just tell the assistant (“I went for a run”). Kept in Habits.md in your vault. A missed day isn't failure: never miss twice.

      Routines

      Things the assistant does on a schedule, on its own, while the app is open: each run is its own conversation and you get a notification.

      Skills

      Save a workflow once, run it again any time: type /name in the chat, say one of its trigger phrases, or click Run. You can also ask the agent to “make this a skill” after it did something for you.

      Evolution

      Ask the agent for a new feature or change (“add a dark/light toggle”, “make the face bigger”) and it edits its own code. Every change is checked and recorded here, so you can inspect it, revert it, or restore any earlier version.

      Select a change to see exactly what was modified.
